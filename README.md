# YouTube Search Downloader

A Python terminal application that searches YouTube and downloads videos or audio using yt-dlp.

## Features

- Search YouTube from terminal
- Display video title
- Display channel
- Display view count
- Display duration
- Download video + audio
- Download audio only
- Download video only
- Select video quality
